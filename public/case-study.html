The Problem

India has more crypto users than any country — but apps still speak a language beginners never learned.

01

The words shut people out

Gas. Slippage. L2. Limit order. Every unknown word quietly tells the user this app was not built for them — so they leave rather than feel stupid.

02

Fear beats curiosity

Real money, no undo, nobody to ask. People reach the buy screen and simply stop. Fear was the #1 reason first-timers quit before their first trade.

03

No native currency support

Existing apps show balances in USD or BTC decimals. Indian users never see ₹ — the one number they actually understand and care about.

04

AI is an afterthought

When doubt strikes — right before a trade — there is nowhere to turn. AI assistants are buried in menus, not present at the moment of decision.

Design Workflow

From Research to Reality

Dec 1

Project Kickoff

Defined problem space: beginner crypto investors in India. Set north-star metric: first-trade completion rate.

Dec 5

Desk & User Research

Analysed WazirX, CoinDCX, Binance. Interviewed 8 users aged 18–24. Finding: language and fear of irreversible mistakes were the top drop-off triggers.

Dec 10

Insights & Persona Creation

Built the "Riya" persona: 22-year-old, first-time investor, comfortable with UPI but terrified of crypto jargon.

Dec 18

User Flows & Wireframing

Mapped 14 core user journeys. Reduced the home-to-trade flow from 7 taps to 3.

Dec 24

Validation & Iteration

Moderated usability tests. Iterated the Buy/Sell screen 3x until 6/8 participants completed their first simulated trade without assistance.

Jan–Feb

High-Fidelity Frontend Build

Full React implementation with live market data, Framer Motion animations, custom CSS design tokens, and a dark glassmorphism visual language.

Built With

Frontend Engineering

Modern tooling chosen to deliver native-feel performance in a web browser.

⚛

React.js + Vite

Component-driven SPA. 2,316 modules. 571ms build time. Sub-second HMR during development.

FM

Framer Motion

Spring-physics page transitions, scroll-linked header blur, SVG path-drawing splash, tap-scale micro-interactions.

CTX

Context API + useReducer

Custom Redux-like architecture with deep-merged localStorage hydration. Zero crashes across version updates.

CSS

Design Token System

CSS variables (tokens.css) for all colors, surfaces, typography. Instant dark-mode consistency across 25+ screens.

API

CoinGecko API

Live market data via custom useCoinGecko React hook with smart caching and graceful error fallback states.

CD

Vercel + GitHub CI/CD

Auto-deploy on every push to main. Globally distributed CDN. Zero-config. Zero downtime.

Key Technical Achievements

Scroll-Linked Glassmorphism

useScroll + useTransform interpolates backdrop-filter:blur and opacity in real time as the user scrolls.

SVG Path-Drawing Splash

Framer Motion pathLength keyframes animate the actual logo.svg — each stroke draws itself on boot.

Mobile-First Screen Architecture

Custom PhoneFrame + Screen wrappers enforce safe-area insets and consistent spacing across all 25+ routes.

Advanced Chart Component

Renders MA, EMA, BOLL, SAR, MACD on HTML Canvas with a custom WebGL-inspired ShaderBackground.
